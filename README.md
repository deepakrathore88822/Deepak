# 🎵 Lyrify Cinema: AI Music-to-Lyrics Frontend

This repository contains the completely self-contained frontend for the **Lyrify** AI Audio Pipeline project. It is perfectly structured for immediate deployment on **GitHub Pages**, providing a live project link you can add to your B.Tech CSE placement resume.

## 🚀 Live Demo Deployment Steps
To make this live on the internet, follow these exact steps:

1. **Create a new Repository** on GitHub (e.g., `lyrify-cinema`).
2. **Upload these two files** (`index.html` and `README.md`) directly to the root of your new repository.
3. In your GitHub repository, go to **Settings**.
4. On the left sidebar, click on **Pages**.
5. Under "Build and deployment", set the **Source** to `Deploy from a branch`.
6. Select your `main` (or `master`) branch and click **Save**.
7. Wait 1-2 minutes, and your site will be live at `https://<your-username>.github.io/<your-repo-name>/`!

## 🌟 Key Features included in `index.html`
- **Cinema Mode Synchronized Lyrics:** High-precision auto-scroll with glowing large-scale font animations centered on the current audio frame.
- **Dynamic Ambient Backdrop:** Real-time blurred ambient lighting behind video based on playback state.
- **Bilingual Subtitles Toggle:** Switch effortlessly between original song vocals and translated lyrics.
- **Custom Upload Support:** Users can click "Upload Custom Song / Video" to test with their own local `.mp3` or `.mp4` files.
- **Built-in Interview Architecture Guide:** Clicking "Architecture & Interview Guide" opens a modal explaining the backend Deep Learning pipeline (Demucs + Whisper + LLM) to recruiters.
